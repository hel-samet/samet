# samet

Personal portfolio website of Hel Samet: designer & web developer.

## Pages

- **Home**: 3D hero, selected work, stats, latest posts
- **About**: profile with a 3D flip card
- **Work**: case studies
  - [TrueVisions International School](https://truevisions.edu.kh/)
  - [MISPP International School](https://mispp.edu.kh/)
  - [IT Solution Digital](https://itsolutiondigital.com/)
- **Blog**, **Resume**, **Contact**

## Tech

Plain HTML, CSS and JavaScript with no build step. The 3D scenes use [Three.js](https://threejs.org/) (loaded from a CDN).
Includes light/dark mode, a mobile slide-in menu, and reduced-motion support.

## Run locally

Serve the folder with any static server, for example:

```bash
python -m http.server 8000
```

Then open http://localhost:8000/.
